# 婷婷科一

给 C1/C2（含自动挡 C2）学员使用的免费科目一基础练习网站。

## 当前功能

- 顺序练习、随机练习和按知识点分层的 100 题模拟考试
- 错题自动收录、错题重练与收藏
- 题目进度、正确/错误数量和模拟记录保存在当前浏览器
- 答题后立即显示免费、自有表述的简短解析
- 路权、左转和右转题的网页动态演示
- 可添加到 iPhone 主屏幕；首次完整载入后，文字题库、错题和进度可离线使用

## iPhone 离线使用

第一次用 Safari 打开网站，等首页出现“已可离线使用”，再点“分享”→“添加到主屏幕”。以后从主屏幕图标打开，即使没有网络或没有开启 VPN，也可以练习完整文字题库；学习记录仍只保存在这台手机的当前网站数据中。

题目配图采用按需缓存：已经在联网时打开过的图片可以离线查看，尚未打开过的外部图片仍需要网络。这样不会批量复制来源不明或受版权保护的商业题图。

## 2026 题库

网站只读取 `data/questions-2026.json`。原始 2022 开源数据完整保存在 `data/questions-archive-2022.json`，清洗、去重和审计脚本位于 `scripts/`。

题库以 MIT 许可的开源数据为基础，剔除明显不适合 C1/C2 的大车、摩托车和校车专属细节，删除旧标志标线与低价值重复题，并依据公开的现行法规补充少量高频考点。它不是商业 App 私有题库，也不代表公安机关实时考试原题。

```bash
npm run build:questions
npm test
```
