# 婷婷科一

给 C2 自动挡学员使用的免费科目一基础练习网站。

## 当前功能

- 顺序练习与随机练习
- 100题模拟考试
- 错题自动收录与错题重练
- 收藏题目
- 答题后立即显示免费解析
- 路权、左转和右转题的网页动态演示
- 练习记录保存在当前手机浏览器，无需注册

## 题库说明

网站运行时读取 `AgentMystia/driving-test-subject1` 整理的基础题库，其数据源追溯至 MIT 许可的 `doupoa/DrivingTestSubjectOne`。

该题库基准为 2022 年，不是官方实时题库。它适合打基础，但涉及法规、记分、罚款和地方新增内容的题目，需要结合现行规定及最新商业题库复核。

## 数据来源

- https://github.com/AgentMystia/driving-test-subject1
- https://github.com/doupoa/DrivingTestSubjectOne

## 使用

直接打开 `index.html`，或使用 GitHub Pages 发布。项目无需安装依赖。
